About StudentHub

A student-first portal for campus information and participation.

Our mission

StudentHub brings useful campus resources into one clear and accessible interface. Students can discover events, create an account, and find help without navigating many disconnected pages.

What this project demonstrates

  • Semantic HTML and accessibility
  • Responsive CSS layouts
  • JavaScript interaction
  • PHP and MySQL integration
